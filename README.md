# CommitCraft

Generate high-quality Git commit messages powered by Gemini AI.

## Features
- Generates commit messages from staged diffs
- Inserts directly into the VS Code Source Control commit box
- Uses Google AI Studio (Gemini) models

## Usage
1. Stage your changes.
2. Run **CommitCraft: Generate Commit Message** from the Command Palette.
3. The AI-generated message appears automatically in the commit box.

## Configuration
- **CommitCraft: Gemini API Key** – set your Gemini key.
- **CommitCraft: Model** – choose `gemini-1.5-flash` or `gemini-1.5-pro`.
